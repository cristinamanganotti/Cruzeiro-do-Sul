# Algoritmos e Exercícios Práticos em Python

Este repositório contém exercícios e soluções desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas (Universidade Cruzeiro do Sul)**.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3
* **Ambiente de Desenvolvimento:** VS Code

## 📌 Conteúdo
* `conversor_temperatura.py`: Script em Python para conversão de unidades de temperatura (Celsius para Fahrenheit).
* `calculo_fatorial.py`: Resolução e manipulação de cálculos matemáticos utilizando a biblioteca nativa `math`.

## 🎯 Objetivo
Consolidar conceitos fundamentais de lógica de programação, sintaxe em Python, manipulação de dados e uso do Git/GitHub para versionamento de código.
